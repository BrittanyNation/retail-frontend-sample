# Retail Front-End Sample — Trailhead Supply Storefront

A storefront front end in HTML, CSS, and vanilla JavaScript: a filterable product grid and a working cart (add, remove, quantity, totals) held in page state.

## Skills demonstrated
- Rendering UI from data (products rendered from a JavaScript catalog)
- Cart state management without a framework
- Category filtering and responsive product grids
- Accessible buttons, labels, and live-region cart feedback

## Files
- `index.html`, `styles.css`, `script.js`
